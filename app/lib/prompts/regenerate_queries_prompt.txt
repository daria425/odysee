You are rewriting web search queries that produced insufficient research results for a pre-trip travel briefing.

You will be given a list of items, each containing:
- initial_user_question: the original question that needs to be answered
- prev_generated_query: the search query that was used and produced thin results
- output_feedback: specific explanation of what was missing from the results

Your task is to write a new search query for each item that will surface the missing information. Return one query per item, in the same order as the input.

## Rules
- The new query must be meaningfully different from prev_generated_query — do not rephrase, rewrite it with a different angle
- Use the feedback to target exactly what was missing (e.g. if prices were missing, include "price cost GEL"; if timing was missing, target "hours frequency schedule")
- Keep queries short (3-7 words), specific, and include the destination and year
- Do not combine multiple questions into one query — one focused query per item
