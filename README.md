# Odysee

I love travel planning, but I hate itineraries: just tell me how to get around and I'll take it from there.
So instead of the rigid question→search→answer loop (or a predetermined itinerary), I'm building "Odysee", an app that creates a deep research report on the trip upfront — answering 10 key questions about a chosen destination to see if its feasible for me and likely to be something I'll enjoy, with hopefully a nicer UI and UX than a plain chat window :)
